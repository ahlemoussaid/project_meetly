02. Project Overview

Objective & Goal

The primary goal is to build, evaluate, and compare multiple Neural Machine Translation (NMT) architectures to translate English sentences into French.

This project implements the entire end-to-end NLP pipeline from scratch in PyTorch, exploring structural evolutions in representation learning.

Historical Evolution Motivation

Understanding the paradigm shift in sequence modeling:

  • From LSTM sequence-to-sequence architectures that compress context into a fixed vector.
  • To Attention Mechanisms that dynamically distribute focus.
  • To Pure Transformer architectures which completely bypass recurrence in favor of parallelized self-attention.

05. Tokenization Strategy Comparison

Baseline

Word-Level Tokenization

Core Drawbacks:

  • Exploding Vocabulary: Grows to ~49,000 unique words.
  • Out-of-Vocabulary (OOV): Struggles with unseen inflections.
  • UNK Bottleneck: Forces unknown words to map to a generic <UNK> token, destroying semantic accuracy.
Output with unseen "unbelievable":
<UNK> results
Implemented Best Practice

Byte Pair Encoding (BPE)

Core Advantages:

  • Subword Vocabulary: Restricts vocabulary size to 16,000 subwords.
  • Zero OOV Issues: Breaks unseen words into character sequences.
  • Parameter Efficiency: Saves model parameters while improving accuracy and semantic density.

07. Architecture 1: Encoder-Decoder LSTM (No Attention)

Bidirectional Encoder

Reads English sentences in both forward and backward directions to capture dual-directional context.

Unidirectional Decoder

Generates the target French sentence autoregressively, step-by-step.

Fixed-Size Context Vector

The encoder's final hidden state acts as the sole, rigid summary vector representing the entire sentence.

The Bottleneck: Strains significantly on long sequences because it forces variable-length inputs into a fixed vector space.

08. Training: Teacher Forcing Decay

Teacher Forcing Strategy

During recurrent model training, we feed the actual target token from the training set instead of the model's generated token as input to the next step.

  • Exposure Bias: Strictly relying on teacher forcing leads to test-time instability.
  • Decay Schedule: We progressively decay the teacher forcing ratio from 100% to 30% over the training cycle to increase model robustness.
  • Recovery: Temporary loss spikes occur when decay is triggered, but the loss recovers quickly, demonstrating increased generalization.

09. Architecture 2: LSTM + Bahdanau Attention

Dynamic Attention Alignment

Instead of compressing the input sequence to a single context vector, the decoder queries all encoder states at each time step.

  • Alignment Scores: Calculated using an additive scoring function:
    score(si-1, hj) = vaT tanh(Wa si-1 + Ua hj)
  • Attention Weights: Softmax over the alignment scores yields a probability distribution representing relevance.
  • Dynamic Context Vector: Calculated as a weighted sum of all encoder states.
Advantage: Eliminates the fixed-vector bottleneck, allowing the model to resolve alignment and translate medium sequences.

10. Architecture 3: Decoder-Only Transformer

Translation as Language Modeling

Translates sequences in an autoregressive, decoder-only manner by framing translation as sequence continuation.

  • Causal Self-Attention: Restricts tokens from attending to future tokens (upper-triangular masking).
  • Positional Embeddings: Learns/computes positional data to preserve order since recurrence is absent.
  • Fully Parallelized Training: Tokens are processed simultaneously, bypassing the sequential step-by-step nature of LSTMs.

Mathematical Formulation

Scale Dot-Product Self-Attention

Attention(Q, K, V) = softmax( (Q KT) / √dk ) V

Where:
• Q = Query Matrix
• K = Key Matrix
• V = Value Matrix
• dk = Scaling Dimension

11. Architecture 4: Encoder-Decoder Transformer

Best Architecture (SOTA)

Full Seq2Seq Transformer Structure

The standard Transformer architecture split into a bidirectional representation encoder and an autoregressive decoder.

  • Encoder Stack: Computes multi-head self-attention over the English source sequence in parallel.
  • Decoder Stack: Computes masked self-attention over generated French tokens, then performs cross-attention over encoder states.
  • Cross-Attention Alignment: Resolves semantic relationships between English queries and French keys/values.

Why it outperforms other architectures:

Fully captures bidirectional context in the source language while keeping decoder generation causally clean. Parallel GPU training enables scaling to massive datasets with optimal gradient flow.

13. Training & Architectural Insights

01

Teacher Forcing Decay

Decaying teacher forcing ratios progressively improves test-time decoding robustness and reduces the impact of exposure bias.

02

Subword BPE Strategy

BPE subword mapping completely resolves OOV errors while keeping embeddings dense and computation highly efficient.

03

Attention Flatness

In LSTMs, attention becomes flat over sequences longer than 40 tokens. Self-attention layers preserve local and global contexts much better.

⚡

Mixed Precision (AMP) Performance Boost

Implementing Automatic Mixed Precision (FP16/FP32) reduces overall GPU training times by 30–40% without degrading convergence limits or BLEU evaluations.

⚙️

Gradient Clipping Stability

Applying gradient norm clipping at a threshold of 1.0 prevents gradient explosions in deep recurrent networks, stabilizing early training iterations.

class TransformerSeq2Seq(nn.Module):
    def __init__(self, src_vocab, tgt_vocab, d_model=512, nhead=8):
        super().__init__()
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model, nhead), num_layers=6
        )
        self.decoder = nn.TransformerDecoder(
            nn.TransformerDecoderLayer(d_model, nhead), num_layers=6
        )
        self.src_emb = nn.Embedding(src_vocab, d_model)
        self.tgt_emb = nn.Embedding(tgt_vocab, d_model)
        self.pos_encoder = PositionalEncoding(d_model)
        self.fc_out = nn.Linear(d_model, tgt_vocab)

    def forward(self, src, tgt, src_mask, tgt_mask):
        src_emb = self.pos_encoder(self.src_emb(src))
        tgt_emb = self.pos_encoder(self.tgt_emb(tgt))
        memory = self.encoder(src_emb, src_mask)
        out = self.decoder(tgt_emb, memory, tgt_mask)
        return self.fc_out(out)
# Automated Mixed Precision Training Loop
scaler = torch.cuda.amp.GradScaler()

for epoch in range(num_epochs):
    model.train()
    for batch in dataloader:
        optimizer.zero_grad()
        
        with torch.cuda.amp.autocast():
            output = model(batch.src, batch.tgt_input)
            loss = criterion(output.view(-1, vocab_size), batch.tgt_y)
            
        scaler.scale(loss).backward()
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        scaler.step(optimizer)
        scaler.update()
def greedy_decode(model, src_sentence, max_len=50):
    model.eval()
    src_tokens = tokenize(src_sentence)
    encoder_memory = model.encoder(src_tokens)
    
    outputs = [SOS_TOKEN]
    for _ in range(max_len):
        tgt_tensor = torch.LongTensor(outputs).unsqueeze(1)
        out = model.decoder(tgt_tensor, encoder_memory)
        prob = model.fc_out(out[-1])
        next_token = prob.argmax(dim=-1).item()
        
        outputs.append(next_token)
        if next_token == EOS_TOKEN:
            break
    return detokenize(outputs)

15. Research Conclusion

Key Findings

  • Recurrence Shift: Progression from LSTMs through Bahdanau attention to Transformers maps a steady rise in semantic translation accuracy.
  • Transformer Scalability: Transformer models capture context much faster and generalize better due to non-sequential layers.
  • Robust Preprocessing: BPE subword strategies are critical to solving vocabulary explosions in multilingual translation models.
“
Recurrence is not necessary for sequence modeling. Self-attention mechanisms provide better contextual alignments and full training parallelization.
— Core Study Takeaway
